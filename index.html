Unidad 1

Introducción a los Métodos Numéricos

1.1 Importancia de los métodos numéricos ▾

Los métodos numéricos son técnicas mediante las cuales es posible formular problemas matemáticos de tal forma que puedan resolverse usando operaciones aritméticas. Son herramientas fundamentales en ingeniería y ciencias aplicadas porque permiten resolver problemas que no tienen solución analítica o cuya solución es muy compleja.

En el proceso de solución de problemas por medio de computadoras, se requieren los siguientes pasos:

  • Especificación del problema: Identificar perfectamente el problema, sus limitaciones, variables y resultados deseados.
  • Análisis: Formular el algoritmo de solución con pasos ejecutables en computadora.
  • Programación: Traducir el algoritmo a un lenguaje de programación.
  • Verificación: Probar exhaustivamente el programa para eliminar errores.
  • Documentación: Preparar instructivos para que otros puedan usar el programa.
  • Producción: Ejecutar el programa con los datos de entrada para obtener soluciones.
1.2 Cifras significativas, precisión, exactitud ▾

Cifras significativas: Son los dígitos de un número que consideramos no nulos. Todos los dígitos distintos de cero son significativos. Ejemplo: 8723 tiene cuatro cifras significativas.

Precisión y exactitud: La exactitud es lo cerca que el resultado de una medición está del valor verdadero. La precisión es lo cerca que los valores medidos están unos de otros.

Incertidumbre: Grado de alejamiento entre las diversas aproximaciones a un valor verdadero. Puede derivarse de falta de información o desacuerdo sobre lo que se sabe.

Sesgo: Alejamiento sistemático del valor verdadero. A diferencia del error aleatorio, el sesgo es consistente y puede ser controlado o neutralizado.

1.3 Tipos de errores Programa ▾

Error de redondeo: Se origina al realizar cálculos cuando es imposible tomar todas las cifras que resultan de operaciones aritméticas, teniendo que retener solo un número limitado de cifras.

Error por truncamiento: Ocurre cuando se interrumpe un proceso que requiere un número infinito de instrucciones para hallar la solución exacta.

Error absoluto: Diferencia en valor absoluto entre el valor real y el valor aproximado: Ea = |Vreal - Vaprox|

Error relativo: Error absoluto dividido entre el valor real: Er = Ea / |Vreal|

Error porcentual: Error relativo multiplicado por 100: Ep = Er × 100%

1.5 Métodos iterativos ▾

Un método iterativo trata de resolver un problema matemático mediante aproximaciones sucesivas a la solución, empezando desde una estimación inicial. Esto contrasta con los métodos directos, que tratan de resolver el problema de una sola vez.

Los métodos iterativos son muy útiles para resolver problemas que involucran un número grande de variables (a veces del orden de millones), donde los métodos directos tendrían un coste prohibitivo.

Características principales:

  • Utilizan aproximaciones sucesivas.
  • Requieren un valor inicial.
  • Funcionan mejor en problemas grandes.
  • Permiten reducir el tiempo de cálculo.

Unidad 2

Métodos de Solución de Ecuaciones

2.1 Métodos de intervalo ▾

Los métodos de intervalo son técnicas numéricas utilizadas para encontrar raíces de ecuaciones no lineales. Se basan en reducir progresivamente el intervalo de búsqueda de la solución hasta alcanzar la precisión deseada. Su característica principal es que no solo aproximan el valor de la raíz, sino que también acotan el intervalo que la contiene, lo que proporciona una garantía sobre la ubicación de la solución.

Para aplicar un método de intervalo, es necesario que se verifiquen las condiciones del Teorema de Bolzano: la función debe ser continua en el intervalo cerrado [a, b] y cambiar de signo en sus extremos, es decir, f(a)·f(b) < 0. Entre los métodos más conocidos de esta categoría se encuentran el método de bisección y el método de Regula Falsi.

Teorema de Bolzano: Si f es continua en [a, b] y f(a)·f(b) < 0, entonces existe al menos un c ∈ (a, b) tal que f(c) = 0.

2.2 Método de bisección (Bolzano) Programa ▾

El método de la bisección o también llamado Método de Bolzano, parte de una función F(x) y un intervalo [x₁, x₂] tal que F(x₁) y F(x₂) tienen signos contrarios. Si la función es continua en este intervalo, entonces existe una raíz de F(x) entre x₁ y x₂.

Una vez determinado el intervalo y asegurada la continuidad, se evalúa la función en el punto medio xm. Si F(xm) y F(x₁) tienen signos contrarios, se reduce el intervalo a [x₁, xm]; en caso contrario, se reduce a [xm, x₂]. El proceso se repite hasta que la diferencia entre los dos últimos valores de xm sea menor que una tolerancia prefijada.

Pasos del método:

  • Elija valores iniciales x₁ (inferior) y x₂ (superior) que encierren la raíz: f(x₁)·f(x₂) < 0.
  • Calcule la aproximación: Xr = (x₁ + x₂) / 2.
  • Si f(x₁)·f(Xr) < 0, la raíz está en [x₁, Xr]; haga x₂ = Xr.
  • Si f(x₁)·f(Xr) > 0, la raíz está en [Xr, x₂]; haga x₁ = Xr.
  • Si f(x₁)·f(Xr) = 0, Xr es la raíz exacta.
  • Repita hasta alcanzar la tolerancia deseada.

Convergencia: El error después de n iteraciones es En ≤ (b - a) / 2ⁿ⁺¹. El método siempre converge si se cumplen las condiciones iniciales.

▶ biseccion.py
# Método de bisección para f(x) = x³ - x - 2 def f(x): return x**3 - x - 2 def biseccion(a, b, tol): if f(a) * f(b) >= 0: return None while (b - a) / 2 > tol: c = (a + b) / 2 if f(c) == 0: return c elif f(a) * f(c) < 0: b = c else: a = c return (a + b) / 2

2.3 Método de aproximaciones sucesivas (punto fijo) Programa ▾

El método de aproximaciones sucesivas consiste en generar funciones convergentes bajo un esquema iterativo partiendo de la función original. Se basa en el siguiente teorema:

Teorema de convergencia: La raíz de cualquier subfunción extraída de una función f(x) obtenida por una iteración convergente es también una raíz de f(x).

Ejemplo: Sea f(x) = 5 sen x - 3x, la subfunción sen(x) tiene como raíz x = 0, la cual resulta ser también raíz de f(x).

El método requiere una función g(x) tal que x = g(x). Partiendo de un valor inicial x₀, se genera la sucesión: xₙ₊₁ = g(xₙ).

Condición de convergencia: Si |g'(x)| < 1 en un entorno de la raíz, el método converge localmente.

▶ punto_fijo.py
# Método de punto fijo para √N # g(x) = (x + N/x)/2 (método de Newton para raíz cuadrada) def punto_fijo(N, x0, tol): x = x0 for _ in range(100): xn = (x + N/x) / 2 if abs(xn - x) < tol: return xn x = xn return x

2.4 Métodos de interpolación ▾

Los métodos de interpolación para resolución de ecuaciones utilizan aproximaciones polinómicas para estimar raíces.

Método de la secante: Variante del método de Newton que no requiere calcular derivadas. Aproxima la derivada mediante diferencias finitas:

xₙ₊₁ = xₙ - f(xₙ)·(xₙ - xₙ₋₁)/(f(xₙ) - f(xₙ₋₁))

Converge más rápido que la bisección (orden ≈ 1.618, el número áureo).

Interpolación cuadrática inversa: Usa tres puntos para construir un polinomio cuadrático y estimar la raíz. Más robusta que la secante.

Método de Ridder: Combina bisección con interpolación exponencial, ofreciendo convergencia rápida y garantizada.

2.5 Aplicaciones Programa ▾

Ingeniería: Los métodos de intervalo y aproximaciones sucesivas se utilizan para calcular raíces de ecuaciones que modelan fenómenos físicos. En termodinámica se emplean para resolver ecuaciones de estado como Van der Waals. En mecánica de fluidos, para determinar el factor de fricción mediante la ecuación de Colebrook-White.

Economía y finanzas: Cálculo de tasas internas de retorno (TIR) y puntos de equilibrio en modelos de oferta-demanda no lineales.

Unidad 3

Métodos de Solución de Sistemas de Ecuaciones

3.1 Métodos iterativos (Jacobi y Gauss-Seidel) Programa ▾

Los métodos iterativos son técnicas eficientes para resolver sistemas de ecuaciones lineales, especialmente cuando se trabaja con matrices grandes y dispersas.

Método de Jacobi: Despeja cada variable en función de las demás usando valores de la iteración anterior. Todas las nuevas aproximaciones se calculan exclusivamente con valores previos.

Método de Gauss-Seidel: Mejora a Jacobi utilizando valores actualizados tan pronto como están disponibles. Generalmente converge más rápido.

Condición de convergencia: La matriz debe ser diagonalmente dominante: |aᵢᵢ| > Σ|aᵢⱼ| para todo i.

▶ gauss_seidel.py
# Sistema: 4x + y = 9, x + 3y = 7 # Despejando: x = (9 - y)/4, y = (7 - x)/3 def gauss_seidel(): x, y = 0, 0 for _ in range(20): x = (9 - y) / 4 y = (7 - x) / 3 return x, y

3.2 Sistemas de ecuaciones no lineales ▾

Un sistema de ecuaciones no lineales incluye términos como potencias (x²), productos (xy), funciones trigonométricas (sen x), exponenciales, etc. Estos sistemas son inherentemente más complejos que los lineales.

Linealización: Técnica común que aproxima el sistema no lineal por uno lineal alrededor de un punto de interés, válido localmente.

Comportamientos complejos posibles:

  • Múltiples puntos de equilibrio: Varias soluciones estacionarias.
  • Ciclos límite: Trayectorias cerradas de evolución.
  • Caos: Comportamiento aparentemente aleatorio y sensible a condiciones iniciales (efecto mariposa).
3.3 Iteración y convergencia Programa ▾

Tanto para sistemas lineales como no lineales, los métodos iterativos se basan en el concepto de punto fijo: reescribir el sistema como x = F(x) y generar la sucesión x⁽ᵏ⁾ = F(x⁽ᵏ⁻¹⁾).

Criterios de convergencia:

  • Cota de error: Se define una tolerancia y se detiene el proceso cuando la diferencia entre iteraciones es menor que ese valor.
  • Número máximo de iteraciones: Se establece un límite para evitar ciclos infinitos.

La convergencia no está garantizada para cualquier sistema; depende de la forma de las ecuaciones, la aproximación inicial y las propiedades matemáticas.

▶ verificar_dominancia.py
# Verificar si una matriz es diagonalmente dominante def es_diagonal_dominante(A): for i in range(len(A)): suma = sum(abs(A[i][j]) for j in range(len(A)) if j != i) if abs(A[i][i]) <= suma: return False return True

Unidad 4

Diferenciación e Integración Numérica

4.1 Diferenciación numérica Programa ▾

La diferenciación numérica aproxima derivadas mediante fórmulas de diferencias finitas basadas en series de Taylor.

Diferencia hacia adelante (O(h)): f'(x) ≈ [f(x+h) - f(x)] / h

Diferencia centrada (O(h²)): f'(x) ≈ [f(x+h) - f(x-h)] / (2h)

Segunda derivada: f''(x) ≈ [f(x+h) - 2f(x) + f(x-h)] / h²

La diferencia centrada converge cuadráticamente: al reducir h a la mitad, el error se reduce a la cuarta parte.

▶ diferenciacion.py
# Derivada numérica de f(x) = x² def derivada_centrada(x, h): return ((x+h)**2 - (x-h)**2) / (2*h) # Exacto: f'(x) = 2x

4.2 Integración numérica (cuadratura) Programa ▾

La integración numérica aproxima integrales definidas cuando no existe solución analítica o la función solo se conoce en puntos discretos.

Regla del punto medio: ∫ f(x)dx ≈ (b-a)·f((a+b)/2)

Regla del trapecio: ∫ f(x)dx ≈ (b-a)/2 · [f(a) + f(b)]

Regla de Simpson 1/3: ∫ f(x)dx ≈ (b-a)/6 · [f(a) + 4f((a+b)/2) + f(b)]

Las versiones compuestas dividen el intervalo en subintervalos para mayor precisión. Simpson requiere número par de subintervalos.

▶ simpson.py
# Integración de f(x)=x² con Simpson compuesto def f(x): return x**2 def simpson(a, b, n): h = (b - a) / n suma = f(a) + f(b) for i in range(1, n): suma += (4 if i%2 else 2) * f(a + i*h) return suma * h / 3

4.3 Integración múltiple y método de Monte Carlo ▾

La integración múltiple en dos o más dimensiones sufre la "maldición de la dimensionalidad": los métodos tradicionales requieren un número de puntos que crece exponencialmente con la dimensión.

Método de Monte Carlo: Utiliza muestreo aleatorio para aproximar integrales. La estimación es: I ≈ V·(1/N)·Σ f(x̄ᵢ), donde V es el volumen de integración.

La incertidumbre disminuye como 1/√N, independiente del número de dimensiones. Para reducir el error a la mitad, se necesitan 4 veces más muestras.

Variantes avanzadas: Muestreo estratificado, muestreo por importancia, algoritmo MISER.

Aplicaciones: mecánica cuántica, finanzas, inferencia bayesiana, simulaciones estadísticas.
